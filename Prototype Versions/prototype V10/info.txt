1. EXECUTIVE SUMMARY & OBJECTIVES
--------------------------------------------------------------------------------
The next evolution of NeXusWeb moves beyond the limitations of standard browser
embedder wrappers (such as Electron) to establish a sovereign, memory-safe,
high-performance desktop web browser architecture.

Key Objectives:
- Eliminate over 70% of industry zero-day attack vectors by replacing C++ core
  process management with a memory-safe Rust kernel.
- Achieve 100% native web compatibility (passing Cloudflare Turnstile, Google
  OAuth, banking portals, and WebGPU hardware rendering without false-positive
  bot flags).
- Enforce military-grade OS-level process sandboxing (Windows AppContainer).
- Deliver forensic zero-trace ephemeral memory scrubbing upon tab destruction.
- Reduce base application memory footprint from ~450MB down to <45MB.


2. THE 5-LAYER SOVEREIGN ARCHITECTURE
--------------------------------------------------------------------------------

[ Layer 1: Sovereign UI Shell ]
  - Framework: React 18 + Vite (Obsidian Dark Theme, Custom Controls, Tabs HUD)
  - Bridge: Tauri 2.0 / Native Rust IPC Controller (Zero Node.js runtime exposure)
  - Memory Footprint: ~15MB - 35MB for the complete UI shell

[ Layer 2: Memory-Safe Rust Security Kernel ]
  - Language: Rust (guaranteed memory safety, zero Use-After-Free, no buffer overflows)
  - Modules:
      * Process & Lifecycle Manager
      * Cryptographic Network Shield (ECH / Oblivious DoH)
      * Ephemeral RAM Scrubbing Vault (secure_zero_memory on tab close)
      * TPM 2.0 / Windows DPAPI Hardware-Bound Credential Storage

[ Layer 3: Dual-Engine Execution Pipeline ]
  - Engine A (Hardened Native Chromium / CEF Engine):
      * Pure native BoringSSL TLS handshake (standard JA3/JA4 fingerprint matching Chrome)
      * Native Direct3D12/Vulkan WebGPU/WebGL acceleration
      * 100% pass rate on Cloudflare Turnstile, reCAPTCHA, and Google Sign-in
  - Engine B (Air-Gapped Sovereign Engine - Servo / Rust WebRender):
      * Used in "Strict Sovereign Air-Gap Mode"
      * Renders untrusted / suspicious URLs completely outside Chromium V8
      * Immune to all known Chromium zero-day exploits

[ Layer 4: OS-Level Micro-Sandboxing ]
  - Windows AppContainer / Low-Integrity Process Isolation:
      * 0 Filesystem Access: Tabs cannot read or write to user directories.
      * 0 Registry Access: Tabs cannot inspect or modify system registry keys.
      * Capability-Restricted Sockets: Network traffic strictly routed through Rust shield.

[ Layer 5: Quantum & Cryptographic Network Stack ]
  - Encrypted Client Hello (ECH / ESNI): Encrypts domain names in TLS handshakes.
  - Oblivious DNS-over-HTTPS (O-DoH): Cryptographic relay decoupling user IP from DNS queries.
  - Built-in WireGuard & Onion Proxy Bridge routing.
